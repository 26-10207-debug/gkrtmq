# 덤캔런 관리자 PC 처리기

Node 22.13 이상과 프로젝트 의존성이 설치된 관리자 PC에서 실행합니다. 추가 유료 검색·OCR 서비스는 사용하지 않습니다. 한국어·영어 OCR 모델은 첫 사용 때 내려받아 `.indexer/ocr-cache`에 보관합니다. 서버에 저장된 색인은 PC가 꺼져 있어도 검색할 수 있습니다.

프로젝트 안의 `.indexer/config.json`에 사이트 주소와 **색인 전용 인증값**을 저장합니다. 이 폴더는 Git에서 제외됩니다. 인증값은 Sites의 비밀 환경 변수 `INDEXER_TOKEN`과 같아야 합니다. 계정·초안 조회 권한은 없습니다. 인증을 취소하려면 Sites의 값을 바꾸고 배포합니다.

```json
{"site":"https://사이트주소","token":"관리자가 발급한 32자 이상의 인증값","ocr":"auto"}
```

```sh
node scripts/indexer/run.mjs status
node scripts/indexer/run.mjs seed
node scripts/indexer/run.mjs run
```

`run`은 한 번에 자료 하나를 처리하고 대기열이 비면 종료합니다. Ctrl+C를 한 번 누르면 현재 구간을 저장한 뒤 멈춥니다. 다시 `run`을 실행하면 이어갑니다. PC 강제 종료는 임대 시간이 끝난 뒤 재시도하며 최대 3회입니다. 지원하지 않는 파일·손상 파일은 상태와 이유를 남기며 원본을 보존합니다. 재시도는 `retry contribution:자료ID`로 요청합니다. 처리기 버전이 바뀐 파일도 이 명령으로 다시 읽을 수 있습니다.

`run --max-jobs=2`는 최대 두 작업만 처리하는 점검용 실행입니다. `--no-crawl`은 해당 실행의 외부 출처 확인을 생략합니다. 일반 `run`은 처리 중 날짜가 바뀌면 허용된 출처를 하루 한 번 확인합니다.

기타 명령:

- `inventory`: 공개 자료 목록을 로컬 `.indexer/inventory.json`에 저장
- `pause` / `resume`: 서버 대기열 일시 중지 / 재개
- `crawl`: 허용된 외부 출처를 확인. 실행 중 하루 한 번, 출처별 최대 100페이지. 현재 출처 정책은 제목·설명·원문 링크만 보관합니다. 접근 제한·실패 사유는 출처 상태에 기록합니다.
- `activate` / `rollback`: 검증된 새 검색 사용 / 한 릴리스 동안 남겨 둔 이전 검색으로 복귀

원본은 메모리에서 읽으며 본문·인증값을 로그에 출력하지 않습니다. ZIP은 256항목·압축 해제 16MB, 파일은 20MB, PDF 렌더는 최대 1600만 픽셀로 제한합니다. HWP는 미지원이며 HWPX XML 본문은 지원합니다. Office의 수식은 문자열로만 읽습니다. 코드·HTML·매크로는 실행하지 않습니다. 원본 이미지의 크기·OCR 정확도 때문에 일부 완료가 될 수 있습니다.

자동 결제·유료 서비스 전환은 없습니다. 서버가 429/507 또는 저장 한도 오류를 반환하면 처리를 중지합니다. 저장 용량·전송량은 기존 Sites/D1/R2 한도를 사용합니다.
